# インスピレーションモード検証記録（2026-08-28）

| 確認項目 | 結果 |
|---|---|
| 一覧の全動画数 | 4,835件 |
| 完全ランダムの抽選母集団 | 4,835件から抽選と表示 |
| 完全ランダムの再抽選 | 初回位置 4,761 / 4,835 から、再抽選後 2,476 / 4,835 へ変更 |
| テーマ指定の旧挙動 | MV選択時に横断テキスト照合で1,963件となり、一覧のMV分類1,237件と不整合 |
| 修正方針 | プルダウンの各選択値を対応カテゴリだけで厳密にAND照合し、全公開動画を候補母集団にする |
| 既存データの安全性 | 一部カテゴリの未定義slugでテーマ選択が停止したため、未定義値を除外して照合するよう修正 |

テーマ指定の修正後は、Vitestのカテゴリ別AND照合と未定義値を含む回帰を含む118件、ならびに型検査を通過している。HMRによる画面再マウント後に、MV条件の候補数が1,237件と一致することを再確認する。

再読込後に完全ランダム・テーマ指定の切替とテーマ選択画面の表示を確認し、未定義slugによる画面停止が解消していることを確認した。次にMV選択時の候補数を再確認する。

MVを選択後、テーマ指定は画面停止せず、1,246件を母集団として表示・抽選した（抽選位置 874 / 1,246）。サイドバーの表示件数1,237件との差分9件は、カテゴリ表示名ではなく既存の正規化slugも照合対象とする抽選仕様によるものかを、コード上で追加確認する。

ジャンル集計はslugだけを数える一方、インスピレーションは選択肢名またはslugのいずれかで照合する。したがって、旧データのslug欠損・表記揺れがある9件も「MV」としてテーマ候補に残る。テーマ指定で表示された1,246件は、MVとして保存されているすべての公開候補を取りこぼさないための件数である。
