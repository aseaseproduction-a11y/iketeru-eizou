# 日次公開映像収集巡回

更新日: 2026-08-19

## スケジュール

| 項目 | 設定 |
|---|---|
| 名称 | 日次・公開映像収集巡回 |
| 実行時刻 | 毎日 09:00 JST |
| 実行方式 | Manusエージェント型・新規タスク |
| 有効期限 | 2027-08-19 |
| 状態 | 有効 |

## 安全条件

エージェントは収集元台帳を取得し、公式公開ページ上で当日新規と判断できるYouTube・Vimeo候補だけを送信する。ログイン必須・公開性不明・削除・非公開・埋め込み不可・掲載タイトルと動画URLを結べない候補は送信しない。

サイト側は、動画IDとURLの一致、公開oEmbed、公式掲載タイトルとの類似、既存動画ID重複を再検証する。通過した候補だけを登録し、実行結果は `dailyCollectionRuns` に保存する。

## 初期収集元

映像作家100人、Vook、ALINCOLONY、ALLd.、Video Refs、BOVA、LIGHT THE WAY、高橋貴士、白田英輔、BB-NAVI、動画NOW、ONE MEDIA、および指定された制作会社公式サイトを初期台帳へ登録する。エージェントは公開性を検証できない場合、登録せず保留する。
