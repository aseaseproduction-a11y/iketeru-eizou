# Vook「イケてる映像」掲載ページの監査

対象URL: https://site.vook.vc/iketeru-eizou?c=b&utm_campaign=website&utm_medium=email&utm_source=sendgrid.com

確認日: 2026-08-19

## 公開構造

- Vookの公式ページには「すべての映像(454)」とカテゴリ別の掲載件数が表示される。
- 静的HTMLからは `iketeru_{動画ID}` 形式のカードアンカーを494件、YouTube URLを432件、Vimeo URLを21件検出した。
- 各カードは、外部動画URL、公式ページ内のタイトル、`item-tags`のジャンル・商材・演出タグを同じアンカー要素に含む。
- 例: `https://www.youtube.com/watch?v=WvFsPFtAojs` はカードタイトル「オーイシマサヨシ - ハイメンテナンスガール [Official Video]」、公式カードタグ「MV」「実写」を含む。

## 抽出方針

Vookカードに明示された動画URL・タイトル・タグを候補化し、公開oEmbedによる動画ID・正規URL・タイトル照合と既存DBの重複監査を行う。確認済み動画にはVook公式ページを出典として記録する。

## 照合・登録結果

| 区分 | 件数 |
|---|---:|
| 公式カードから構造化 | 453 |
| oEmbedで三重照合済み | 429 |
| oEmbed未取得またはタイトル不一致 | 24 |
| 既存DBの重複 | 423 |
| 新規登録 | 6 |

新規6件には、Vook公式掲載ページのURL、公式カードのタイトル・タグ、掲載元としてのVookをキュレーションメモに記録した。Vookは掲載元であり制作会社ではないため、制作項目は根拠のない値で補完していない。24件は公開oEmbedでID・URL・タイトルを確認できないため、保留とした。

## 既存重複動画への明示タグ補完

Vook公式カードのタグを既存重複419件へ反映し、未入力項目だけを公式明示カテゴリで補完した。

| 内容 | 件数 |
|---|---:|
| Vook公式タグの監査記録を保存 | 419 |
| 未入力ジャンルを補完 | 7 |
| 未入力商材を補完 | 4 |
| 未入力演出を補完 | 7 |
| 未入力トーンを補完 | 0 |

既存カテゴリ値は上書きせず、公式カードの全タグを `allTags` と根拠監査へ追加した。
