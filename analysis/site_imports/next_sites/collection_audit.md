| 対象 | 保留理由 |

| ALLd. | 保存済み公式DOMから32件のプロジェクト詳細URLを復元してNuxt詳細・`_payload.json`・`_payload.js`を確認したが、プロジェクト名とVimeo動画IDを同一公式根拠内で結べなかった。 |
| FAVVID | 公開Notionの189件の詳細ページを確認したが、カードに直接表示されない外部動画URLは公開HTMLから取得できなかった。タイトル検索のみでは登録しない。 |
| oddfellows / P.I.C.S. / LIKI / 竹留 / 平井秀司 / Notion / 佐倉 / maxilla / ワチャジャック / 太陽企画 / BABEL LABEL / UKMVA / GEEK PICTURES / D-Walker | 初期公開HTML・公式作品経路・利用可能なCMSを確認したが、今回の自動取得範囲でタイトルと外部動画URLを一対一にできる公開根拠を確保できなかった。推測登録を避けて保留。 |

## 品質条件

動画ID、正規URL、oEmbedタイトルの三重照合を満たさない55候補は保留とした。既存データとのID・URL・正規化タイトル重複64件も追加登録していない。
