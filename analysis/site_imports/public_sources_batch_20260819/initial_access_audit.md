# 指定サイト群の初期アクセス監査

実施日: 2026-08-19

| サイト | 初期結果 | 収集方針 |
|---|---|---|
| [CM bb-navi](https://www.bb-navi.com/cm-douga/index-news.html) | 公開アクセス可。最新CM一覧・Page2〜12・連続再生用の公開動画構造を確認。 | YouTube配信URLが明示される動画のみをページ単位で収集し、公開性・重複を確認する。 |
| [BOVA](https://awardg.sendenkaigi.com/bova) | 公開アクセス可。現行回の応募サイトと過去受賞作品導線を確認。 | 過去受賞作品ページから動画URLが明示される作品を収集する。 |
| [Creshore](https://creshore.jp/home#/) | ユーザーのログイン済み画面を確認。クリップ動画・受賞作品・CM好感度等の閲覧導線が表示される。 | ユーザーがアクセス可能な公開・クリップ作品だけを対象にし、外部動画URLと公開性を確認できるものを収集する。 |
| [Video Refs](https://video-refs.com/) | 公開アクセス可。カテゴリ別の外部動画カードを確認（例: モーショングラフィックス83件、インタビュー30件、観光82件）。 | カテゴリページ・動画一覧から外部動画URLとカードの明示カテゴリを収集し、公開性・重複を確認する。 |
| [動画NOW!!](https://douganow.jp/) | 公開アクセス可。公式チャンネル公開済みと説明されるCM記事を確認。約4,638ページのページネーションを表示。 | 記事内に公式YouTube等のURLが明示される公開動画だけを対象にし、公式公開性・重複を確認する。 |
| [ONE MEDIA](https://www.onemedia.jp/) | 公開アクセス可。プロモーション事例導線と、ショート動画・SNSマーケティングの公式制作実績を確認。 | 公式プロモーション事例ページに明示される外部動画URLを収集し、公開性・重複を確認する。 |
| [Reclike](https://reclike.com/l/s21cf) | 公開アクセス可。個別公開リストの動画カード・タイトル・タグを確認。例: MotionGraphics_2Dは1,420件、MOTION COMICは37件。 | 指定12リストのカードから外部動画URLとタイトルを取得し、公開性・重複を確認する。 |
| [karekitsune Vimeo Likes](https://vimeo.com/karekitsune/likes) | 公開アクセス可。1,814 Like・152ページの公開一覧、動画カード、RSS導線を確認。 | 公開Like一覧のVimeo動画IDをページ単位またはRSSから取得し、公開oEmbedで再生可能な動画だけを対象にする。 |

> Creshoreのログイン済み状態は、ユーザーが明示的に指定した収集依頼の範囲で閲覧にのみ利用する。動画の追加・変更等の外部操作は行わない。
