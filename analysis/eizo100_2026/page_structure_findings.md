# 映像作家100人 2026掲載ページの初期構造監査

対象ページ: https://eizo100.jp/archives/category/2026

## 確認結果

- ページ見出しは「映像作家100人2026」で、掲載順はランダムと明記されている。
- 初期表示では作品カードごとに、クリエイター名、日本語・英語表記、カテゴリ、作品名、公開年、尺、作品説明、サムネイルが確認できる。
- 画面末尾には `Loading...` が表示され、一覧はスクロールに応じて追加読み込みされる構造である。
- 初期スクロール範囲で、YouTube等の直接動画URLは本文から一律には確認できない。各作品カードまたは作品詳細ページのリンク構造を取得し、代表動画URLを別途三重照合する必要がある。

## 登録時の扱い

「映像作家100人 2026」カテゴリ掲載自体を公式出典として保存する。一方で、動画サイトへ登録する作品は、動画ID・動画URL・作品タイトルを照合できたものに限定する。画像のみの作品や動画URLを確認できないカードは、掲載記録として保留リストに残す。

## 公式APIによる全件確認

- WordPress REST API `https://eizo100.jp/wp-json/wp/v2/video?categories=1045&per_page=100&page={page}&_embed=1` を使用すると、ページネーション2ページで全191件を取得できる。
- 191件の内訳はYouTube URL 138件、Vimeo URL 36件、動画URLなし15件、外部URL2件である。YouTube・VimeoのIDを抽出できた候補は170件だった。
- YouTube/Vimeoの公式oEmbedと、映像作家100人の作品名を正規化して照合した結果、ID・動画URL・タイトルが一致した候補は65件、タイトル不一致103件、oEmbed取得不可2件だった。
- 65件については、公式の映像作家100人作品詳細URL、配信プラットフォームURL、oEmbedタイトルを保存し、登録前の三重照合根拠としている。
