## 2. 第2優先（既存 DB メイキング／BTS × 本編 8組）：ベースライン誤差監査 完了

追加ダウンロードゼロで、Iketeru の既存 DB（`iketeru_knowledge.db`、読み取り専用）内の「本編単独の `ai_analysis`」と「公式メイキング／VFX ブレイクダウンの `ai_analysis`」を 8組突き合わせた結果、**初期ベースラインの明確な弱点が数値と具体例で判明した**（詳細は `priority2_bts_vs_main_audit.json`）。

### ベースライン実測値（8組）
- **主手法カテゴリ（実写／ミニチュア／VFX合成／3DCG／2D）の一致率**: **5 / 8（62.5%）**（※目標 ≥ 85% に対し **-22.5pt の改善余地**！）
- **重大な誤認・ハルシネーション（事実と逆の断定）が起きた作品**: **3 / 8（37.5%）**

### 発見された 3大誤認パターン（極めて有益な知見）
1. **最新 VFX（ブルースクリーン＋流体CG＋照明反射合わせ）を「実炎ロケ・アナログ特撮」と逆断定（2件）**：
   - **LE SSERAFIM×ILLIT×KATSEYE 'ICONIC BY MISTAKE'**：本編分析は「安易な CG 合成に逃げず実際に巨大な炎を焚いた」「巨大な歯列のアナログ美術」と断定していたが、公式 VFX Breakdown（Infinite VFX）では**全面ブルースクリーン＋CG 炎パーティクル＋未塗装 3DCG 口腔メッシュ合成**だった。
   - **Uber TVCM「第六感篇」**：本編分析は「都心ビジネス街ロケ＋簡易 2D 背景歪み」と断定していたが、公式 BTS では**全面グリーンバックスタジオ＋実物タクシー持ち込み＋大型 MRMC ロボットアームカメラ撮影**だった。
2. **MP4 未視聴のままメタデータだけで手法・規模を推測して大ハズレ（1件）**：
   - **Britbox 'See it Differently'**：未視聴一次評価で「2D / After Effects 推定 / Tier 1（30万以内）」と記録されていたが、公式 BTS では **14時間かけた巨大スタジオの実写セット転換＋モーションコントロール撮影（Tier 4）**だった。
3. **実制作の隠れリグ工程の抜け（的中した 5組の共通課題）**：
   - Honda「Hakoniwa」、Google Chrome「がんばれ！くろーむ」、Mrs. GREEN APPLE「クスシキ」、ポカリスエット、サカナクション「怪獣」の5組は主手法が的中した一方、完成画面から消されている**「金属アーム／真鍮リグ固定」「全身緑タイツの黒子ワーク」「黒十字トラッキングマーカー」「3Dプリンタ出力＋筆塗り」**といった再現上もっとも重要な実務工程が抜け落ちていた。

### Iketeru の分析・`craft_recipes` 改善へ直接活かせる 3ルール
1. **断定表現の禁止と両可能性の併記**：炎・自然光・空間歪み・実写風 3D など境界が曖昧なカットで「実写に違いない／CG では不可能」と断定させず、`confidence: inferred` と併記して「実写セット案／クロマキー＋インタラクティブライト合成案」の両ルートを明示する。
2. **未視聴レコードでの手法・Tier 推定の禁止**：MP4 未視聴時は手法・ツール・Tier を `unverified` に固定し、推測値で DB を汚染しない。
3. **実務リグ・ポスト消去工程の標準化**：コマ撮り・VFX 系レシピ生成時に「リグ固定＋ペイントアウト（リグ消し）」「トラッキングマーカー配置」「モーションコントロール撮影」を必須確認項目へ追加する。
