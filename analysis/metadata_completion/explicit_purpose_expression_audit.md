# 明示根拠による用途・表現補完監査

実施日: 2026-08-19

## 補完ルール

動画タイトルまたは公式掲載タグに、用途・表現を直接示す語がある場合だけ補完した。用途は指定された10選択肢、表現は指定された7選択肢に限定した。作品の内容を視聴・推測して分類する処理は行っていない。

| 根拠例 | 保存値 |
|---|---|
| `Music Video`、`MV`、`M/V` | MV |
| `TVCM`、`Web CM`、`Commercial`、`広告` | プロモーション |
| `オープニング`、`エンディング`、`Opening`、`Ending` | OPED |
| `インタビュー`、`Teaser`、`ブランディングムービー`、`サービス紹介` | 対応する許容用途 |
| `Animation`、`アニメーション`、`実写`、`3D`、`2D`、`イラスト`、`生成AI` | 対応する許容表現 |

## 結果

| 指標 | 件数 |
|---|---:|
| 対象（用途または表現が未入力） | 2,721件 |
| 更新動画 | 1,485件 |
| 用途を補完 | 1,165件 |
| 表現を補完 | 787件 |
| 補完後の用途未入力 | 1,556件 |
| 補完後の表現未入力 | 1,934件 |

残件は公式タイトル・公式タグに用途または表現の明示語がなく、現時点で根拠だけでは確定できないものとして未入力を維持する。
