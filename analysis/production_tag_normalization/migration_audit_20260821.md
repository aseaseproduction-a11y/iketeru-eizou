# 制作クレジット構造化・表記統一 監査記録

実施日：2026-08-21

## 実施内容

既存の`productions`に保存されていた制作会社・制作者・役割名の連結値を、人物または会社の`name`、担当`roles`、種別`entityType`に分離して`productionCredits`へ保存した。保存時には、役割名・会社名・個人名を別々に検索できるよう、個人・会社名を`productions`へ、役割名を`allTags`へ反映した。

代表表記は公開クレジットの表記を基礎に統一する。初期の明示的な同義語対応には、`株式会社ライト・ザ・ウェイ`→`LIGHT THE WAY Inc.`、`Eisuke Shirota`→`代田栄介`、`CHOCOLATE.inc`→`CHOCOLATE Inc.`を含める。対応関係を確認できない日英別表記は、同一人物・同一会社だと推測して統合しない。

## 正規化ルール

| 入力例 | 構造化後 |
|---|---|
| `Agency : CHOCOLATE.incDirector : EISUKE SHIROTA...` | `CHOCOLATE Inc.`（エージェンシー）、`代田栄介`（監督・編集）などに分離 |
| `制作者（映像作家100人掲載者）：HARU` | `HARU`（制作者） |
| `プロダクション・マネージャー：三隅光治` | `三隅光治`（プロダクションマネージャー） |
| `ディレクター：しらたき` | `しらたき`（監督） |

## 保留方針

`不明`、説明文、クレジットの一部だけでは人物・会社名として確定できない文字列は、空の構造化クレジットとして維持する。これらは名称や役割を推測で追加せず、今後の制作会社公式サイト・公式動画説明欄・公式SNS照合の対象とする。

- `production_credits_dry_run.json`：移行前の全件監査結果
- `production_credits_apply.json`：実行時の変更対象記録

## クレジット精度・推定読み補完（2026-08-21）

ユーザーの追加指示に従い、役割付きの英文クレジット、音楽・出演だけのクレジット、投稿ページのナビゲーション文、日英別表記を再監査した。音楽・歌唱・演奏・作詞・作曲・編曲・ミックス等は映像制作の制作者フィルターから除外し、同一人物が映像制作の役割も持つ場合だけ、その役割を維持する。

|---|---:|---|
| 今回の自動補正 | 106動画 | 英文役割分離、非映像系役割の除外、ナビゲーション文除外、代表表記統一を更新時刻保護付きで適用 |
| 最終ドライランの追加補正候補 | 0動画 | 再適用不要を確認 |

| 入力例 | 保存・分類結果 |
|---|---|
| `vocals performed by 牧野由依` | 牧野由依とボーカルへ分離後、音楽系のみのため制作クレジットから除外 |
