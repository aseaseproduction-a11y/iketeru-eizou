## 照合の 4 観点と欠落チェック
実際の動画と既存分析（`ai_analysis`）・シーン（`scenes`）を次の観点で照合してください。

1. **時刻**: `scenes` の各シーンの開始・終了時刻が実際の映像と何秒ずれているかをシーンごとに確認する。
   - 各シーンのずれ幅 `shift_sec` は、`max(|実開始秒 - 分析開始秒|, |実終了秒 - 分析終了秒|)`（秒、小数第1位まで）で算出する（そのシーン自体が存在しない・幻覚の場合は `null`）。
   - 1.0 秒未満の丸め誤差は食い違いに含めない。
   - 1.0 秒以上 3.0 秒以下のずれは `軽微`（種類: `時刻のずれ`）、3.0 秒を超えるずれは `重大`（種類: `時刻のずれ`）として `discrepancies` に記録する。
2. **映像の内容**: 人物・物・場所・文字（テロップ・タイトル等）の記述が実際の映像にあるかを確認する。
   - 実際の映像に無いものを書いていたら種類 `幻覚`（重さ: `重大`）。
   - 人物や物を別のものと取り違えていたら種類 `取り違え`（人物の取り違えは `重大`、物・細部の小さな誤りは内容に応じ `重大` または `軽微`）。
3. **技法**: カメラワーク・編集・合成・モーション・トランジション等の記述が実際の映像と合っているかを確認する（種類: `技法の誤り`）。
4. **音**: BGM・効果音・台詞・ナレーション・音ハメ等の記述が実際の音声と合っているかを確認する（種類: `音の誤り`）。
5. **欠落・基本情報**:
   - 作品の主要な場面・展開・構成要素が分析やシーンから抜けていたら種類 `欠落`（主要な場面の欠落は `重大`）。
   - 尺・画面比率（アスペクト比）など作品の基本情報に誤りがあれば種類 `基本情報の誤り`（重さ: `重大`）。

## 食い違いの重さの基準
- **重大**:
  - 幻覚（実在しない映像・文字・演出の記述）
  - 人物の取り違え
  - 3 秒を超える時刻のずれ（`shift_sec > 3.0`）
  - 主要な場面の欠落
  - 尺や画面比率など作品の基本情報の誤り
  - 技法・音における明確かつ本質的な誤認（例：静止画を実写カメラ移動と誤認、無音を大音量BGMと誤認など）
- **軽微**:
  - 1〜3 秒の時刻のずれ（`1.0 <= shift_sec <= 3.0`）
  - 細部の言い回しや色・数の小さな誤り、軽度な技法・音の表現ズレ

## 判定基準（厳密適用）
`discrepancies` の件数（`major` = 重大件数、`minor` = 軽微件数）および全体構成の一致度から、次の 3 段階で判定してください。
- **合っている**: 重大 `0` 件、かつ軽微 `2` 件以下
- **一部違う**: 重大 `1〜3` 件、または（重大 `0` 件かつ）軽微 `3` 件以上
- **大きく違う**: 重大 `4` 件以上、または分析の構成の大半が実際の映像と合わない
