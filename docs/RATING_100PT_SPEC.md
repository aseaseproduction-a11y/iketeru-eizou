# 100点満点評価（ルーブリック合算＋15段階ランク自動マッピング）連動仕様書

既存の 15 段階評価（`S+` 〜 `D-`）を完全維持したまま、0〜100 点の細かい点数差を **MySQL / API / Vercel UI / Google スプレッドシート / ローカル `iketeru-creative-studio`** の全系で連動させるための統一仕様です。

## 2. 5観点 × 20点 ルーブリック定義

- **ディレクション (`direction`, 100点)**
  1. `hookAndStructure`（冒頭フック・構成力: 0–20）
  2. `originality`（演出アイデア独自性: 0–20）
  3. `rhythmAndSync`（テンポ・リズム・音ハメ: 0–20）
  4. `worldAndSubject`（被写体・世界観の説得力: 0–20）
  5. `intentAchievement`（企画意図の到達度: 0–20）
- **技術 (`technique`, 100点)**
  1. `cinematographyAndArt`（撮影・照明・作画: 0–20）
  2. `editingAndMotion`（編集・モーション精度: 0–20）
  3. `colorAndLook`（カラグレ・ルック・美術: 0–20）
  4. `soundAndMix`（音響・MA・ミックス: 0–20）
  5. `polishAndFinish`（仕上げ・完成度: 0–20）
- **総合 (`overall`, 100点 — 基準値＋シナジー補正方式)**
  - 計算式: `overall = clamp(round(direction × 0.55 + technique × 0.45) + synergyAdjustment, 0, 100)`
  - 演出主軸（55% : 45%）をベースとしつつ、企画突破力・独自性・目的到達度に応じて `synergyAdjustment`（`-5` 〜 `+5`）の柔軟な補正を許容（補正が `0` 以外のときは `rationale` に理由を必須記載）。

## 3. Google スプレッドシート（`イケ動自動分析`）連動列仕様

スプレッドシート側には以下の 4 列を追加してください（既存ランク列はそのまま維持）：

| 追加列名 | 型 | 説明 |
| :--- | :---: | :--- |
| `AI総合点(100)` | 整数 0–100 | 総合スコア |
| `AI演出点(100)` | 整数 0–100 | ディレクション5観点合計 |
| `AI技術点(100)` | 整数 0–100 | 技術5観点合計 |
| `AI評価内訳JSON` | テキスト | 5観点×20点内訳 JSON（任意） |

**点数セル（例: `M2`）から 15 段階ランクを自動計算するスプレッドシート数式**:
```excel
=IF(M2="","",IFS(M2>=97,"S+",M2>=93,"S",M2>=90,"S-",M2>=86,"A+",M2>=82,"A",M2>=78,"A-",M2>=73,"B+",M2>=68,"B",M2>=63,"B-",M2>=57,"C+",M2>=51,"C",M2>=45,"C-",M2>=35,"D+",M2>=20,"D",TRUE,"D-"))
```
