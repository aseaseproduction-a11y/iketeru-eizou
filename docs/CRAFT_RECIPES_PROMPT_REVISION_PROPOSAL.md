- **非接触保証**: **Phase 2 凍結採点ルール（`T_award=83`, `T_low=63`, `gemini-4-neon-high`, `v1_baseline`, `phase2_hybrid_v1` および凍結 13ファイル）には一切触れません。**

## 用語のやさしい説明
- **プロンプト（指示文）**: AI に「何を観察し、どんな形式・ルールで分析を書くか」を伝える設計書。
- **ハルシネーション（事実誤認・作り話）**: AI が映像から確認できない制作手法（例：「本物の火を焚いた」等）を、それらしく断定して書いてしまう現象。
- **インタラクティブライト（環境反射光）**: CG の炎や爆発が俳優の顔や服を照らすように、スタジオ側でも同色の照明を当てて合成の馴染みを高める技法。
- **ペイントアウト（リグ消し）**: 撮影時に人形や俳優を支えていた金属アーム・ワイヤー・黒子（くろこ）を、編集・合成工程で背景から消す作業。
- **MRMC（モーションコントロール・ロボットアーム）**: コンピュータ制御で同じカメラ軌道をミリ単位で繰り返し動かせる大型ロボットアームカメラ。

## 1. 改訂の背景（Track C 第2優先 8組監査で判明した弱点）

既存 DB の「本編単独分析」と「公式メイキング／VFX ブレイクダウン」を 8組突き合わせた結果、現行の分析指示文には以下の構造的な弱点があることが実証されました（詳細：`analysis/craft_calibration_pilot/priority2_bts_vs_main_audit.json`）：

1. **主手法カテゴリ一致率が 5/8（62.5%）に留まり、3/8（37.5%）で重大な逆転誤認が発生**：
   - *LE SSERAFIM×ILLIT×KATSEYE*：ブルースクリーン＋流体 CG 炎＋3DCG 口腔メッシュ合成を「CG では代用不可能な実炎ロケ」「アナログ歯列美術」と逆断定。
   - *Uber 第六感篇*：全面グリーンバック＋MRMC ロボットアーム撮影を「都心ビジネス街ロケ＋簡易 2D 歪み」と逆断定。
   - *Britbox*：MP4 未視聴のメタデータ一次評価のまま「2D / After Effects / Tier 1」と推定し、実態（巨大実写セット転換＋モーションコントロール / Tier 4）と完全に乖離。
2. **的中した 5組でも「完成画面から消されている実制作工程（隠れ工程）」が抜ける**：
   - 金属アーム固定・真鍮リグ・緑タイツ黒子ワーク・黒十字トラッキングマーカー・3Dプリンタ出力＋筆塗りなど、実際に再現しようとしたときに不可欠な工程が落ちていました。

## 2. `craft_recipes` 分析指示文の改訂案（そのまま組み込めるルール文）

現行の `iketeru-production-standards` 第5章（フレーム粒度・`effect_chain`・`primary_tool`）を活かしつつ、**以下の 3大ルールと出力スキーマ追加項目**を分析プロンプトの先頭（厳守憲法セクション）へ組み込みます。

```markdown
## 【改訂ルール：事実性・非断定・隠れ工程の厳守】

### ルール1：実写／CG／特撮の断定禁止と「両ルート併記」
- 完成映像だけを見て「実炎ロケに違いない」「CG では代用不可能」「アナログ美術で組んでいる」「都心ロケを封鎖して撮った」のように、画面外（舞台裏）の撮影条件を断定してはならない。
- 以下の境界ショット（最新 VFX と実写が視覚的に見分けにくい表現）では、**必ず両方の可能性を比較検討し、確信度（`evidence_level`）を明記**すること：
  - 炎・煙・爆発・雨風（実特効 vs 流体 CG パーティクル＋インタラクティブライト合成）
  - 都市背景・大規模セット・車内／車外（実ロケ vs グリーンバック／LED ボリューム＋実車持ち込み）
  - 空間歪み・高速カメラ軌道（ポスト 2D 歪み vs モーションコントロール／ロボットアーム撮影）
  - 精巧なミニチュア・質感表現（実物ミニチュア／3Dプリント造形 vs フル 3DCG）
- 出力には必ず以下を含める：
  - `evidence_level`: `"observed_in_video"`（映像内に直接映る事実） / `"inferred_dual_route"`（実写案・合成案の両可能性あり） / `"confirmed_by_bts"`（公式メイキング・VFX ブレイクダウンで確認済み）
  - `alternative_production_routes`: 境界ショットでは「A案（実写／物理アプローチ）」と「B案（クロマキー／3DCG 合成アプローチ）」の2ルートを簡潔に併記し、どちらを主仮説とするかの視覚的根拠（影・反射・被写界深度・エッジ等）を添える。

### ルール2：未視聴レコードでの手法・ツール・Tier 推定の全面禁止（ハードゲート）
- 動画本体（MP4）または実動画から生成されたコンタクトシート／キーフレーム画像を直接観察していない場合、**表現手法（2D/3D/実写）・使用ソフト・推定再現規模（Tier 1〜4）・`craft_recipes` を一切推測・出力してはならない**。
- 未視聴レコードでは必ず `observation_scope: "metadata_only_unwatched"` とし、以下の項目を `null`（または `"unverified"`）に固定する：
  - `expression_format: "unverified"`
  - `estimated_tools: []`
  - `reproduction_tier: "unverified"`
  - `craft_recipes_eligible: false`（レシピ登録を機械的にブロック）
- これにより、既存のメタデータ一次評価 249本（Britbox `1069311388` 等）のような「未視聴のまま 2D/Tier 1 と誤分類される事故」を構造的に防ぐ。

### ルール3：隠れ工程（リグ・裏方・合成マーカー）の標準チェックリスト
- 完成映像では消去・隠蔽される実制作工程を見落とさないよう、レシピ生成時に以下の 6項目を必ず点検し、該当する可能性がある場合は `hidden_craft_checklist` 欄へ具体的に記載すること：
  1. **支持リグ・ペイントアウト（リグ消し）**: コマ撮り人形の真鍮リグ・ミニチュア気球の金属アーム・ワイヤー宙吊りとポストでのリグ消し工程。
  2. **トラッキングマーカー・クロマキー管理**: グリーン／ブルースクリーン上の黒十字マーカー配置、人物への緑被り（スピル）抑制とエッジ処理。
  3. **カメラ特機・軌道制御**: MRMC モーションコントロール・ロボットアーム、テクノクレーン、水中ハウジング、マルチカメラ／ドローン間の色合わせ。
  4. **物理補助スタッフ・環境演出**: 緑タイツ黒子による小道具／ワイヤー操作、強風送風機、スモーク／ヘイズ、インタラクティブライト（炎や雷の照り返し用LED）。
  5. **デジタル×アナログ造形工程**: 光造形レジン 3D プリント＋筆塗り塗装、発泡スチロール／紙・フェルトの差し替え表情パーツ、物理プリント小道具。
  6. **カラーマネジメントとコンポジット順序**: カメラ Log 入力→露出／WB→ルック（Filmic / AgX / LUT）→グレア／レンズ歪み／グレインの適用順（ノード有無の区別を含む）。
```

| **⑤ 具体性維持チェック（劣化防止）** | — | **100% 合格**（8/8） | 慎重表現のせいで「わかりません」だけの空疎な記述にならず、手元ソフト（AE/Blender/Resolve）で実行可能な具体手順が残っているか |

## 4. 最終検証結果と判断（2026-11-25・Track C 区切り）

### 4-1. 公平なホールドアウト再テスト（新規 10 組・二重盲検）の結果
旧 8 組とは完全に重複しない新規 BTS 付き 10 組（実写主体 2・ストップモーション/ミニチュア 3・ハイブリッド 3・CG/生成AI系 2）を用い、改訂前指示文（`OLD_BASELINE`）と改訂後指示文（`REVISED_3RULE`）をブラインド比較し、独立した盲検審査サブエージェント（無関係 BTS 対照テスト含む）で厳格採点した（詳細：[holdout_fair_ab_eval.json](file:///E:/iketeru-eizou/analysis/craft_calibration_pilot/holdout_fair_ab_eval.json)）。

| 評価指標 | 改訂前 (`OLD_BASELINE`) | 改訂後 (`REVISED_3RULE`) | 判定 |
|---|---:|---:|---|
| ① 主仮説＋実写/デジタル比率の厳格一致 | **7/10（70%）** | **6/10（60%）** | 改訂後が悪化（`ho_05` でハイブリッド逃げによる不一致） |
| ② 逆転誤認がある作品数 / 総箇所数 | 5/10（**19箇所**） | 5/10（**10箇所**） | 作品数は不変、誤断定箇所数は約半減 |
| ③ 隠れ工程 適合率（BTS確認 / 挙げた数） | 28/84（**33.3%**） | 17/50（**34.0%**） | ほぼ横ばい（約 2/3 は BTS で未確認） |
| ④ 無関係 BTS 対照テスト（誤ヒット率） | 0/84（0.0%） | 0/50（0.0%） | 定型占星術ヒットは双方とも 0% |

※**監査ログに関する訂正**: `holdout_fair_ab_eval.json` および `_analysis_audit_log.json` において、各サブエージェントへ渡した指示文（`prompt_text`）は抽出キーの不一致により全 40 件 `null`（未保存）となっていた。今後の検証では指示文の非 `null` 保存を完了条件に組み込む。
