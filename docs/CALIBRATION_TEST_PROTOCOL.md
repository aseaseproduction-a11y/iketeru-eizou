# 較正テスト実施プロトコル（事前固定版・v1）

本プロトコルは、較正テストの実行前にすべての条件・データ分割・合格基準を固定し、結果を見た後の基準変更（後出し調整）を禁止するために策定する。

---

## 1. テストの位置づけ（試しの較正・本番DB非書込）
- 本テストは **「試しの較正（Dry-run）」** として実行し、**本番TiDB / SQLite への書き込みは一切行わない**。
- 結果は採点方式（静止画方式 vs 動画方式）の精度比較および改善目安として扱い、そのまま本番ランクの付け直しには使用しない。

---

## 2. 事前固定する合格基準（結果を見て変更しない）
すべての合否判定は、調整に使っていない **確認用セット（Holdout）** に対する計測値のみで行う。

| 指標 | 対象 | 合格基準（固定） | 算出仕様 |
|---|---|---|---|
| **順位相関（Spearman $\rho$）** | Holdout `craft_benchmark`（14本） | **$\rho \ge 0.85$** | 平均順位法（同点補正付き）＋ブートストラップ95%信頼区間（$B=2,000$）、Kendall's $\tau_b$ 併記 |
| **誤差（Band-distance MAE）** | Holdout `craft_benchmark`（14本） | **$\text{MAE} \le 4.0$点** | 正解ランク帯 $[L_i, U_i]$ 内なら `0`、帯域外なら最も近い端までの点差の平均 |
| **順位の正解率（Pairwise / ROC-AUC）** | Holdout `A-`以上 `craft_benchmark`（14本） vs Holdout `non_award_baseline`（20本） | **$\ge 0.85$** | 受賞・選出作のAI点数 ＞ 非受賞商用作品のAI点数となる組み合わせ割合＋ブートストラップ95%信頼区間 |

- 併記項目：ランク帯別一致率（完全一致率・±1ランク以内一致率）、現代作（`modern_10y`）単体集計、ジャンル別集計。
- **モーションの扱い**：基準作品が1本（`1032202784`）のみのため、**モーションのジャンル別結果は算出・表示せず「未検証」と明記する**（全体集計のみ算入）。

---

## 3. 調整用（Dev）と確認用（Holdout）の事前固定分割
乱数シード `20261122` による層別分割を `analysis/benchmark_split.json` に事前固定する。

- **`craft_benchmark`（34本）**：
  - **調整用（Dev）: 20本** — プロンプト・ルーブリック調整は必ずこの20本（＋Dev非受賞24本）のみで行う。
  - **確認用（Holdout）: 14本** — 調整中は一切参照・最適化せず、最終合否判定のみに使用する。
- **`non_award_baseline`（44本）**：
  - **調整用（Dev）: 24本**
  - **確認用（Holdout）: 20本**
- **参考枠（5本）**：`non_craft_award_reference`（2本）・`purpose_reference_only`（1本）・`audience_award_reference`（2本）は合否判定に含めず参考値として別枠出力する。

---

## 4. 静止画方式 vs 動画方式の並列比較
- 同一の分割（Dev / Holdout）・同一のブラインド条件（既存DBランク・受賞名・タイトル内の賞言及を完全遮断）で、以下2方式を実行し結果を横並び比較する：
  1. **静止画方式（Contact Sheet）**：ffmpeg による代表フレーム一覧画像＋音声/メタ実測値を用いた採点。
  2. **動画方式（Native Video via `read_file`）**：`yt-dlp` で取得したローカル `.mp4`（埋め込み不可6本を含む全件同一方式）を Antigravity ワーカーが `read_file` で直接読み込み、映像の動き・編集リズム・実音声（セリフ・BGM・SE）を含めて採点。
