## 各項目の詳細（本書の記述と現行ツール別再現方法の補足）

### `DIY-001` 坂本渉太 — フラッシュ風アニメ（音楽同期キャラクター）
- **出典**: 『映像制作 D.I.Y.』1（本書 p.8–17 / PDF p.10–19）

#### 本書の記述（要約）
1コマのズレが違和感を生む音楽同期アニメのため、まず楽曲の尺に沿った文字絵コンテで全体構成を組み、短尺でも一目で伝わる記号的なキャラクターをデザインする。ペイントソフト（SAI）で胴体・腕など動きのパーツごとにレイヤー分け（作例では 6 レイヤー）し、After Effects のパペットツールとイージーイーズでモーションを付け、鏡の前で自分の体で覚えたリズムを楽曲 BPM へ合わせ込んだうえで、見せ場ごとに全身とアップのカメラワークを切り替える。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **After Effects**: パーツ分け PSD/PNG を読み込み、`パペット位置ピン`（辞典 ② `AE-020`）＋グラフエディタのイージーイーズ（`AE-034`）でタメを作り、BGM マーカー（拍グリッド）へキーフレームを吸着させる。
- **DaVinci Resolve**: エディットページで BGM のビート位置へマーカーを打ち、Fusion のパーツ別 `Transform`（関節 Pivot）と `Spline` 緩急で音ハメ動作を組む。
- **Blender**: 2D パーツを画像プレーンまたは Grease Pencil で配置し、アーマチュア骨格（辞典 ③ `BL-004`）と VSE 音声波形表示を同期させてアニメートする。

### `DIY-002` 水尻自子 — 手描きアニメ（シンプル線画の質感）
- **出典**: 『映像制作 D.I.Y.』2（本書 p.18–27 / PDF p.20–29）

#### 本書の記述（要約）
紙の手描きならではの生々しい質感と繊細な動きを出すため、画コンテでキメのコマを決めた後、タップ穴を空けた無地の A4 コピー用紙を専用タップで固定し、ライトボックス上で下の絵を透かしながら原画・動画を 1 枚ずつ描く。スキャナーで連番取り込みし、Photoshop で 1 枚ずつ着色・合成した連番フォルダを After Effects へ読み込んで映像化する。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **撮影・現場の工夫**: 現代では紙＋スキャナーの代わりに iPad（Procreate / RoughAnimator）や CLIP STUDIO PAINT でも再現できるが、紙の繊維と鉛筆のかすれを活かしたい場合は高解像度スキャン＋乗算合成が最短。
- **After Effects**: 連番 PNG をフレームシーケンス読み込みし、`解釈 > フレームレート` を低めのコマ数（8〜12fps 等・本書に記載なし・補足目安、または `ポスタリゼーション時間`）に調整して手描き特有のコマ感を保つ。
- **DaVinci Resolve**: メディアプールの「フレーム表示モード：シーケンス」で連番作画を読み込み、カラーページで紙地の白レベルとコントラスト（辞典 ① `COLOR-008`）を整える。
- **Blender**: **`Grease Pencil`**（および辞典 ④ の `GP Animator Desk` / `NijiGPen`）を使えばライトボックス相当のオニオンスキン付きで3D空間内に手描き作画を完結できる。

### `DIY-003` 稲葉まり — 切り絵アニメ（自宅マルチプレーン撮影）
- **出典**: 『映像制作 D.I.Y.』3（本書 p.28–37 / PDF p.30–39）

#### 本書の記述（要約）
手作りならではの紙の影と奥行きを活かすため、絵コンテ（作例では A4 用紙 6 枚分）をまとめた後、画用紙へライトボックスで下描きをトレースして切り絵パーツを制作する。撮影台ではガラス板を複数段重ねる「マルチプレーン・カメラ」手法で物理的な奥行きと自然な被写界深度を作り、デジタル一眼レフで大量コマ撮り撮影を行い、仕上げに After Effects で色紙に描いた追加アニメ要素を重ね合成する。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **撮影・現場の工夫**: 俯瞰固定した一眼カメラ＋定常光ライト（露出・WB・フォーカスを完全マニュアル固定）＋ガラス板またはアクリル板の多段設置で反射を防ぎつつコマ撮りする（テザー撮影ソフト Dragonframe 等が現行定番）。
- **After Effects**: デジタル再現する場合は、スキャンした紙パーツを `3D レイヤー` で Z 軸へ多層配置し、カメラの被写界深度（ブラー）と `ドロップシャドウ` でマルチプレーン効果を擬似再現する。
- **DaVinci Resolve**: Fusion の 3D 空間へ紙パーツの `ImagePlane3D` を奥行き違いで並べ、`Camera3D` の焦点距離・被写界深度を有効にしてレンダーする。
- **Blender**: 切り絵透過 PNG を `Image as Planes` で奥行き別レイヤーに配置し、実ライトによる柔らかな本物の影とカメラの被写界深度（DOF）で物理的にマルチプレーン撮影を再現できる。

### `DIY-004` 菅原そうた — 低予算モーションキャプチャ（Kinect＋MMD）
- **出典**: 『映像制作 D.I.Y.』4（本書 p.38–47 / PDF p.40–49）

#### 本書の記述（要約）
手付けキーフレームに膨大な手間がかかる 3D キャラクターの自然な体の動きを低予算で得るため、家庭用ゲーム機用センサー（Kinect）とフリーソフト MikuMikuDance（MMD）で体の動きをキャプチャし、同時にヘッドホンマイクで台詞音声も収録する。得られたモーションデータを 3DCG ソフト（3ds Max）へ読み込み、Photoshop で作ったテクスチャを貼ってショートアニメ化する。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **撮影・現場の工夫**: 現行環境では Kinect の代わりに、スマホ単体撮影からの AI 骨格推定（Move.ai / Wonder Studio / Rokoko Video / MediaPipe）や iPhone の ARKit 顔キャプチャで同等以上の低予算モーキャプが可能。
- **Blender**: BVH / FBX 形式のモーキャプデータを読み込み、`Auto-Rig Pro`（辞典 ④）や `Rokoko Studio Live` でキャラのリグへリターゲット（辞典 ③ `BL-004`）、表情は `Faceit` で連動させる。
- **After Effects**: 2D キャラであれば Adobe Character Animator の Web カメラ顔・体トラッキング連携でリアルタイム収録し AE へ読み込める。
- **DaVinci Resolve**: Blender 等でレンダリングしたモーキャプ済み 3D キャラ連番と同時収録音声をタイムラインで編集・整音（Fairlight）する。

### `DIY-005` 山口悠野 — おいしいとこ取り GIF アニメ
- **出典**: 『映像制作 D.I.Y.』5（本書 p.48–55 / PDF p.50–57）

#### 本書の記述（要約）
音が入らず短尺ループで観られる GIF アニメの特性に合わせ、細かなラフを描かずシンプルで明快な仕掛け（3D 空間の四角い器へ重力演算で物体を落下・充填させる装置）を直接モデリングしてカメラを配置する。3D ソフトから書き出した `.mov` を After Effects で連番 JPG へ変換し、Web 上の 9 分割フォトセット表示も意識したループ GIF へ仕上げる。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **Blender**: 剛体物理（Rigid Body）＋容器コライダーで落下シミュレーションを組み、開始フレームと終了フレームが視覚的に繋がるループ設計で書き出す（辞典 ③ `BL-001`, 辞典 ④ `Physics Dropper`）。
- **After Effects**: 書き出した連番や動画を読み込んでループ繋ぎの微調整・減色向けコントラスト整理を行い、Media Encoder（または Photoshop / ffmpeg のパレット最適化）で軽量 GIF / WebP 出力する。
- **DaVinci Resolve**: 短尺ループカットのトリミング・色味強調（少ない色数でも映える配色整理）を行い、PNG 連番や MP4 として書き出して GIF 変換へ渡す。

### `DIY-006` TYMOTE — モーショングラフィックス（ロゴを動かす）
- **出典**: 『映像制作 D.I.Y.』6（本書 p.56–65 / PDF p.58–67）

#### 本書の記述（要約）
既存ロゴを数秒のモーションへ昇華させる際、まずロゴ自体を徹底観察して固有の幾何学パーツ（三角形や線など）を抽出する。詳細な絵コンテより先に音楽と同期しやすい一定間隔のタイムフレーム（作例では 4 秒間の動きを黒・カラフル等のグループ別セットで展開）を決め、3D 空間の角度変化で立体文字や三角形が「点→線→面」へ見える視覚トリックを活かしてサウンドと一体化させる。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **After Effects**: ロゴの Illustrator（`.ai`）データを「ベクトルレイヤーからシェイプを作成」し、3D レイヤー回転・`パスのトリミング`（辞典 ② `AE-001`）・グループ別タイミング展開（`AE-023`）で幾何学ロゴモーションを組む。
- **Blender**: SVG インポートしたロゴを押し出し（Extrude）して平行投影カメラの回転で「線→立体」へ変わるモーショングラフィックスを物理的な光影付きで作成する。

実写と CG の違和感をなくし不思議なリアリティを生むため、後処理任せにせず「CG と合成したときに最大限馴染む実写セットとカメラワーク」を事前設計して撮影するアプローチ。現地の写真取材から世界観・グラフィック要素（赤い糸等のモチーフ）を組み立て、CG 合成時の光・質感・カメラ動きを想定してベースとなる実写セット撮影を追い込む（あわせて時間と位置をずらして記録するスリットスキャン表現にも言及）。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **撮影・現場の工夫**: CG 合成用の実写撮影では、①現場の全天球 HDRI 環境光とグレーボール／カラーチェッカーの撮影、②レンズ焦点距離・カメラ高・照明角度の記録、③合成対象と色味がケンカしない背景設計を行うと後段の馴染みが劇的に良くなる。
- **Blender**: 現場で撮った HDRI をワールド照明に設定し、`Shadow Catcher（シャドウキャッチャー）` で実写床面へ CG の影だけを物理的に落とす（辞典 ③ `BL-005`, 辞典 ④ `Perspective Plotter` / `fSpy` / `GeoTracker`）。
- **After Effects**: スリットスキャン表現は `時間置き換え（Time Displacement）` に白黒グラデーション参照レイヤーを当てて再現できる。CG 合成時は背景実写の黒レベル・グレイン・被写界深度を CG 層へ合わせる。
- **DaVinci Resolve**: Fusion の 3D トラッキング＋`Shadow` 合成後、カラーページで実写と CG のシャドウ色・彩度・レンズビネットを統一する（辞典 ① `COLOR-019, COLOR-028`）。

### `DIY-018` 勅使河原一雅 — 映像プログラミング（自動生成モンタージュ）
- **出典**: 『映像制作 D.I.Y.』18（本書 p.178–187 / PDF p.180–189）

#### 本書の記述（要約）
毎回異なる映像体験をプログラムで生成するジェネラティブ映像の構築法。動画ファイルをリアルタイムに前後ジャンプさせても負荷が出ないよう 1 フレームごとの軽量連番素材（当時 Flash タイムライン展開）へ変換し、グラフィック要素は事前制作したうえでデータベースから XML タグ情報を付与。1 フレームごとにタグ参照と `random()` 乱数で次の遷移先を制御し、基底にピアノ音楽を流すことで偶然の映像展開に統一感と情緒を与える。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **After Effects**: 事前レンダリングした連番クリップへ `タイムリマップ`＋`posterizeTime()`・`random()` エクスプレッション（または JSON データ駆動テンプレート）を適用し、音楽トラックと組み合わせて自動編集的なランダムカット映像を生成できる。
- **Blender**: Python スクリプト（辞典 ③ `BL-025`）で JSON/CSV タグを読み込み、VSE のクリップ配置やシェーダー画像シーケンスのフレーム番号を乱数制御して自動モンタージュを生成できる（リアルタイム実行なら TouchDesigner / Processing / p5.js / WebGL）。
- **DaVinci Resolve**: Resolve Python API からメタデータタグ付きビン内クリップをランダム選出・タイムライン自動配置し、共通 BGM とルックノード（辞典 ① `COLOR-028`）を当てて書き出す。

### `DIY-019` 山口崇司 — 音と映像のシンクロプログラミング
- **出典**: 『映像制作 D.I.Y.』19（本書 p.188–197 / PDF p.190–199）

#### 本書の記述（要約）
音と映像をプログラムでリアルタイム完全同期させるインタラクティブ制作の事例。衛星写真モチーフと専用制作したパート別音源を用い、ドラム連打などの打音検出・拾う音の長さ調整・音楽パート制御を **Max/MSP** で構築。一方、カメラにかざした物理カードの写真認識やリアルタイム映像効果描画を **openFrameworks** で実装し、両者を連携させることで演奏やカード操作に応じて即座に音と映像が応答する仕組みを作る。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **After Effects**: 非リアルタイムの動画制作であれば、パート別ステム音源（キック・スネア・シンセ等）ごとに「オーディオをキーフレームに変換」を実行し、数値しきい値＋エクスプレッションでスケール・発光・切替を音へ完全自動同期できる。
- **Blender**: グラフエディタの `キー > サウンドを F カーブへベイク（Bake Sound to F-Curves）` で特定周波数帯（低音ドラム・高音シンバル等）ごとの波形をジオメトリノードやライト強度・シェーダーへ直接駆動させる（リアルタイム演奏同期は Max/MSP・TouchDesigner・OSC 連携）。
- **DaVinci Resolve**: Fusion の Reactor / Audio モディファイア（または外部解析したビートマーカー XML/OTIO 読み込み）で音のアタックに同期した映像エフェクトを駆動する。

### `DIY-020` 作った映像を広めよう（共有されやすい構造と発信）
- **出典**: 『映像制作 D.I.Y.』20（本書 p.198–205 / PDF p.200–205）

#### 本書の記述（要約）
完成した映像を広く届けるための実践知と、当時ネットで大きな反響を呼んだ作家作品の共通点（①言葉を介さず視覚だけで笑えるハイスピード撮影、②わずか数秒で完結するシンプルで気持ちいいループ GIF、③実演パフォーマンスとモーショングラフィックスの融合、④分かりやすい企画コンセプト）を整理し、動画共有サイトや映像コンテストの活用ポイントをまとめている。

#### Gemini による再現方法の補足（現行ツール・撮影の工夫を含む）
- **撮影・現場の工夫**: 現代のショート動画（YouTube Shorts / TikTok / Reels）でも「言葉なし・最初の数秒で視覚のフックが伝わる」「ループして見返したくなる」という構造原理はそのまま通用する。
- **DaVinci Resolve**: 横長本編（16:9・本書に記載なし・補足目安）の完成タイムラインから、視覚フックの強い数秒を切り出して縦長（9:16・本書に記載なし・補足目安）スマートリフレーム版・SNS 用ループ版を同一プロジェクト内で書き出し展開する。
- **After Effects**: 本編のタイトルロゴやキーモーション（`DIY-006`）をそのまま SNS 用ショートバンパーや正方形／縦型ループアニメーションへリサイズ展開する。
- **Blender**: 1つの3Dシーンから `Per-Camera Resolution`（辞典 ④）で横長本編カメラと縦長ショート用カメラを別解像度管理し、一括書き出しできる。
