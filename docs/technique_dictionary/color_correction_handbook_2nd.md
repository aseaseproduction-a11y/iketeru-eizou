## 各項目の詳細（本書の記述とツール別再現方法の補足）

> **用語ミニ解説（よく出てくる基本語）**
> - **ルーマ（Luma / Y'）**: 映像の「明るさ成分」のこと。
> - **クロマ（Chroma）**: 映像の「色成分（色相と彩度）」のこと。
> - **プライマリ補正**: 画面全体に対して行う基本の明暗・色味調整。
> - **セカンダリ補正**: 特定の「色」や「場所（マスク）」だけに絞って行う部分調整。
> - **ラチチュード（ダイナミックレンジ）**: 最も暗い部分から最も明るい部分まで記録できる階調の広さ。
> - **IRE / %**: 波形モニター上で明るさを表す目盛り（0が純黒、100が基準白）。

### `COLOR-001` クロマ・サブサンプリングと10bit/Log素材の耐性
- **出典**: 『カラーコレクションハンドブック 第2版』Ch.1（本書 p.7–11 / PDF p.31–35）

#### 本書の記述（要約）
映像ファイルはデータ容量を抑えるため、明るさに比べて色情報だけを間引く「クロマ・サブサンプリング（4:2:0 など）」を使うことが多い。色情報が少ない素材や 8bit 素材ほど強い色調整や部分切り抜きでノイズや破綻が出やすいため、グレーディングソフト内部の 32bit 浮動小数点処理（4:4:4 相当）を活用しつつ、撮影・中間フォーマットは 10bit や 12bit・Log/RAW のような余裕ある素材が有利である。

#### Gemini による再現方法の補足（本書に記載のないツール固有の操作・設定を含む）
- **DaVinci Resolve**: `プロジェクト設定 > カラーマネジメント` で 32bit 浮動小数点パイプライン（既定）を維持し、デリバーでは `ProRes 422 HQ / 4444` や `DNxHR HQX (10-bit)` で書き出す。4:2:0 素材にキーイングする際は Qualifier の `Denoise / Blur Radius` を併用する。
- **After Effects**: `ファイル > プロジェクト設定 > カラー > 深度` を **16 bpc（本書に記載なし・ソフト固有設定）または 32 bpc（浮動小数点）** に設定し、8bit 処理によるバンディング（階調の縞模様）を防ぐ。
- **Blender**: `出力プロパティ > カラーマネジメント / 出力` で `OpenEXR`（`16-bit Half`（本書に記載なし・ソフト固有設定）または `32-bit Float`）を選択し、コンポジターや DaVinci 側へ色情報を間引かず（4:4:4 相当）渡す。

### `COLOR-002` カラーコレクション環境とモニター基準
- **出典**: 『カラーコレクションハンドブック 第2版』Ch.2（本書 p.23–61 / PDF p.45–89）

#### 本書の記述（要約）
どれほど精密に色を調整しても、モニター自体が色転びしていたり黒が浮いていたりすると正しい判断ができない。測定器でキャリブレーション（色合わせ）した信頼できるメインモニターを 1 台に定め、部屋の壁や背景を無彩色グレーにして適切な視距離を保ち、自動コントラスト補正（ダイナミックアイリス等）を切ることで再現性のある判断ができる。

#### Gemini による再現方法の補足（本書に記載のないツール固有の操作・設定を含む）
- **DaVinci Resolve**: `環境設定 > システム > ビデオ＆オーディオ I/O` から専用出力機器（UltraStudio / DeckLink 等）経由でキャリブレーション済みモニターへ Rec.709 / Gamma 2.4 出力し、`カラーマネジメント > 3DビデオモニターLUT` で補正プロファイルを適用する。
- **After Effects**: `表示 > カラーマネジメントを使用` をオンにし、OS の校正済み ICC プロファイルを反映させたうえで、`プロジェクト設定 > 作業用スペース` を `Rec.709 Gamma 2.4` に統一する。
- **Blender**: `レンダープロパティ > カラーマネジメント` で `Display Device: sRGB / Rec.709` と `View Transform: AgX`（または `Filmic`）を明示固定し、ビューポート背景を中立暗グレーに設定して色順応を防ぐ。

### `COLOR-003` 輝度・ルーマと波形／ヒストグラム解析
- **出典**: 『カラーコレクションハンドブック 第2版』Ch.3.2–3.3（本書 p.79–90 / PDF p.101–112）

#### 本書の記述（要約）
人間の目は赤・緑・青を均等に感じるのではなく、緑（72%）に最も敏感で、赤（約21%）・青（7%）の順に感度が下がる。目視の錯覚に惑わされないよう、画面左右の位置と明るさ（0–100%＋オーバーシュート領域のスーパーホワイト 110%、図3.13）を可視化する波形モニター（Waveform）と、全体分布を示すヒストグラムでコントラストを診断する。

#### Gemini による再現方法の補足（本書に記載のないツール固有の操作・設定を含む）
- **DaVinci Resolve**: カラーページの `スコープ > 波形（Yのみ / Luma）` と `ヒストグラム` を常時表示し、-10〜100 IRE（本書 p.89 / PDF p.111 の IRE 表記にも対応）の範囲内に黒と白がどう分布しているかを確認する。
- **After Effects**: `ウィンドウ > Lumetri スコープ` を開き、`波形（YCbCr / Luma）` と `ヒストグラム` を有効化して画面の明暗分布を数値で確認する。
- **Blender**: `画像エディタ / コンポジタ` のサイドバー（`N` キー）→ `スコープ` タブで `波形（Luma）` と `ヒストグラム` を表示し、ライティング段階の露出バランスを検証する。

### `COLOR-004` Lift / Gamma / Gain と Pivot によるコントラスト拡張
- **出典**: 『カラーコレクションハンドブック 第2版』Ch.3.4–3.5（本書 p.90–105 / PDF p.112–127）

#### 本書の記述（要約）
眠たく霞んだ映像（波形の上下がスカスカの状態）は、Gain（明部）を引き上げて Lift（暗部）を引き下げることで階調全域を使い切る「コントラスト拡張」を行う。さらに Contrast（傾き）と Pivot（明暗の支点）を組み合わせることで、全体の明るさ印象を保ったままコントラスト強度だけを素早く調整できる。

#### Gemini による再現方法の補足（本書に記載のないツール固有の操作・設定を含む）
- **DaVinci Resolve**: `プライマリ・カラーホイール` の `Lift / Gamma / Gain` 下部マスターホイール、または `Contrast` と `Pivot` スライダーを使用（8ノード構成の `03 EXPOSURE` / `04 CONTRAST` に対応）。
- **After Effects**: `Lumetri カラー > カラーホイールとマッチ`（シャドウ／ミッドトーン／ハイライト）または `基本補正 > コントラスト・白レベル・黒レベル` で階調幅を広げる。
- **Blender**: コンポジターの `カラーバランス（Color Balance）` ノードを **`Lift / Gamma / Gain` モード** に設定し、各輝度スライダーで暗部・中間・明部のレンジを拡張する。

### `COLOR-015` HSL キーイング（クオリファイア）とマット精製

### `COLOR-017` ルミナンス分離による明部・暗部の独立グレーディング

### `COLOR-030` クリエイティブルック（ティント／アンダートーン／バイブランス）
- **出典**: 『カラーコレクションハンドブック 第2版』Appendix A.1–A.3（本書 p.556–575 / PDF p.590–610）

#### 本書の記述（要約）
印象的な世界観を作る 3 つの応用技法として、①単色マットを `Overlay / Soft Light / Hard Light` 等の合成モードで重ねて光学レンズフィルター風の非線形な色味を与える「ティント＆カラーウォッシュ」、②暗部〜中間だけにオリーブ緑や青を薄く差し込みつつ肌マスクを減算して血色を守る「アンダートーン」、③すでに鮮やかな色を守りながら彩度の低い色だけを持ち上げる「バイブランス」がある。

#### Gemini による再現方法の補足（本書に記載のないツール固有の操作・設定を含む）
- **DaVinci Resolve**: ①`ジェネレータ（単色）`＋`レイヤーミキサー（Soft Light / Overlay / Hard Light・Key Output Gain で強度調整）` でティント再現。②`ログホイール（Shadow）` または `クオリファイア` で暗部に色を入れ、肌キーを `キーミキサー` 減算してアンダートーン化。③`Color Boost` または `Sat vs Sat` カーブ（左の低彩度側だけ持ち上げる）でバイブランス再現。
- **After Effects**: ①平面レイヤー（単色）を `ソフトライト / オーバーレイ / ハードライト`＋控えめな不透明度で重ねる。②暗部ルミナンスマット＋肌除外マットの調整レイヤーでアンダートーン。③`Lumetri カラー > クリエイティブ > バイブランス`。
- **Blender**: ①コンポジターの `Mix Color（Overlay / Soft Light / Hard Light）` に単色カラーと低 `Factor` を入力。②`ColorRamp（暗部）` から `Cryptomatte（肌）` を減算したマスクで暗部アンダートーン。③コンポジターの `Hue / Saturation / Value` へ低彩度マスク（`Separate HSV` の `S` を反転）を掛けてバイブランスを再現。
