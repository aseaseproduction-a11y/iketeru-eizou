# イケてる映像に追加 — Chrome拡張機能

閲覧中の公開動画・作品ページを、**イケてる映像コレクション**の公開編集画面へ引き継ぐ、Manifest V3形式のChrome拡張機能です。拡張機能は保存APIを直接呼び出しません。URL・ページタイトル・媒体候補を追加画面へ事前入力し、利用者が内容を確認してから保存します。

## 対応するURL

| 種別 | 動作 |
|---|---|
| YouTube / Vimeo | 動画ID、埋め込みURL、YouTubeサムネイル候補を自動入力します。 |
| X / TikTok / Instagram | 投稿URLと媒体候補を入力し、サイト側で公開メタデータ候補を取得します。 |
| その他の公開URL | 「その他の外部サイト」として追加画面を開きます。タイトル・サムネイルを編集して保存できます。 |

## 導入方法

1. 配布ZIPをダウンロードし、ChromeではなくFinder／エクスプローラー等で**展開**します。ZIPファイルのままでは読み込めません。
2. 展開後の `iketeru-eizou-chrome-extension` フォルダを開き、直下に `manifest.json`、`popup.html`、`popup.js` があることを確認します。
3. Chromeで `chrome://extensions` を開き、右上の**デベロッパーモード**を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**を選び、手順2で確認した `iketeru-eizou-chrome-extension` フォルダ自体を指定します。親フォルダ、ZIPファイル、または `manifest.json` 単体は指定しません。
5. ツールバーの拡張機能メニューから「イケてる映像に追加」を固定します。
6. 動画または作品の公開ページを開き、拡張機能を押して**追加画面を開く**を選びます。
7. 開いた画面でタイトル・URL・媒体を確認し、必要なメタデータを追加して**動画を追加**で保存します。同じ動画が登録済みの場合は、重複として案内を表示します。

## プライバシーと権限

拡張機能は `activeTab` 権限だけを要求します。これは利用者が拡張機能を起動したときに限り、現在のタブのURL・タイトルを読むための一時的な権限です。全サイトへの常時アクセス、バックグラウンド収集、閲覧履歴の送信は行いません。
